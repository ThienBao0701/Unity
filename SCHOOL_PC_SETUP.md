# School Computer Setup

1. Install/verify Unity 2022.3.40f1 (or the exact compatible 2022.3 LTS version allowed by the exam).
2. Extract the project folder.
3. In Unity Hub choose Add → Add project from disk.
4. Select the folder containing `Assets`, `Packages`, and `ProjectSettings`.
5. Open the project and wait for import.
6. Open Window → General → Console and check for compile errors.
7. Open the required exam scene.
8. Press Play and verify the required behavior.

For a future exam, do not assume all W1-W5 packages are needed. Install/add only what the actual exam requires.
