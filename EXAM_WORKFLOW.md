# Future Exam Workflow

## Standard Flow

Real Exam Question
→ Analyze every requirement
→ Do NOT assume similarity to W1-W5
→ Inspect current repository
→ Identify reusable code/assets
→ Plan minimal changes
→ Implement only required features
→ Check compile errors
→ Check scene setup
→ Check Inspector references
→ Check Play Mode
→ Review changed files
→ Give final run instructions

## Rules
- The real exam is the source of truth.
- W1-W5 are reference examples only.
- Keep solutions simple and reliable for a university practical exam.
- Avoid unnecessary packages and architecture.
- Do not break existing working functionality unless the exam requires it.
- Never invent unspecified requirements.
- Never claim testing that was not actually performed.

## Final Report Format
1. Requirements understood
2. Implementation completed
3. Files created
4. Files modified
5. Scenes changed/created
6. Packages/dependencies required
7. Inspector/setup instructions
8. How to run
9. Verification status
10. Remaining limitations
